# 🌐 NotesApp Frontend

The frontend of the NotesApp, built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**.

## 🛠️ Features
- **App Router**: Modern navigation and server components.
- **Tailwind 4**: High-performance, engine-driven styling.
- **Client-side Auth**: Manages user sessions via `localStorage`.
- **Responsive UI**: Fully optimized for mobile and desktop.

## 🚀 Development
Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## 📁 Key Pages
- `/`: Landing page with "Get Started".
- `/login`: Secure sign-in form.
- `/signup`: User registration.
- `/dashboard`: Main notes management interface.
